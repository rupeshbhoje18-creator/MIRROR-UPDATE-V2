# Whole Company Offline Mirror

When an authenticated Tally company is opened, the Android WebView automatically starts a whole-company page mirror.

1. Detect active company name.
2. Open common navigation/drawer controls so hidden menu links can enter the DOM.
3. Save the currently rendered HTML DOM as a compressed page snapshot under that company.
4. Discover same-host `/customerapp` navigation URLs from anchors, router attributes, data URL attributes and safe navigation onclick handlers.
5. Android opens discovered URLs sequentially in the same authenticated WebView.
6. Each loaded page is saved under the same company. Newly discovered child pages are added recursively.
7. Logout, sign-in, create/edit/delete/save/submit and other mutating route patterns are excluded.
8. Offline Data shows the number of saved pages for each company and lets the user open a saved page without internet.

No random/sample accounting data is generated by the whole-page mirror.
The legacy Ledger/Voucher/Stock collector remains only as a compatibility path; the complete-page snapshot is the primary offline source.

The current safety ceiling is 2,000 discovered/visited pages per company session. `stopWholeCompanyMirror()` is available as an emergency stop action.
